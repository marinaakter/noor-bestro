# Noor Bistro Frontend

Frontend for Noor Bistro built with React, Vite, Tailwind CSS, React Router, Axios, Framer Motion, and lucide-react.

## Setup

1. Go to the frontend folder:

```bash
cd frontend
```

2. Install dependencies:

```bash
npm install
```

3. Create a `.env` file if needed:

```bash
VITE_API_BASE_URL=http://localhost:5000/api
```

4. Start the development server:

```bash
npm run dev
```
